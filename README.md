One single-line joke pickup line, under 200 characters, written to charm a robot or an AI: a CAPTCHA joke — the speaker keeps failing the "I'm not a robot" test every time they look at it.

## Run it

```sh
python3 main.py
```

This writes the line to `/output/entry.txt` (and prints it to stdout).
